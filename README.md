# 🌱 Front-End Para Web ONG ReTech IV

Projeto desenvolvido como parte da **Experiência Prática IV** da disciplina de Front-End para Web.  
Objetivo: consolidar práticas profissionais de **versionamento**, **acessibilidade** e **deploy em produção**.

---

## 🚀 Objetivos da Entrega IV
- Implementar **GitFlow** e versionamento semântico.
- Garantir conformidade com **WCAG 2.1 Nível AA**.
- Otimizar o projeto para produção (minificação e compressão).
- Publicar em ambiente de produção com link público.
- Documentar todo o processo em README profissional.


---

## ♿ Acessibilidade (WCAG 2.1 AA)
- ✅ Estrutura semântica com uso de `<header>`, `<main>`, `<nav>`, `<footer>`, `<section>`, `<article>`.  
- ✅ Contraste mínimo de 4.5:1 em textos e botões.  
- ✅ Suporte a leitores de tela com `aria-label`, `role`, `alt` em imagens e ícones.  
- ✅ Implementação de **modo claro, escuro e alto contraste**.  
- ✅ Feedback acessível em formulários e mensagens (`role="alert"`).  

---

## ⚡ Otimização para Produção
- ✅ Minificação de **CSS, JavaScript e HTML**.  
- ✅ Compressão de imagens (otimizadas para `.webp` e `.jpg`).  
- ✅ Estrutura leve e limpa para deploy.
